# Assets Directory

This directory contains image assets for documentation.

## Required Assets

Please add the following screenshots and images:

### App Icon
- `app-icon.png` - 128x128 app icon for README

### Screenshots
- `screenshot-iphone.png` - iPhone screenshot (1170x2532 or similar)
- `screenshot-ipad.png` - iPad screenshot (2048x2732 or similar)
- `screenshot-macos.png` - macOS screenshot (1920x1080 or similar)

### Feature Demos
- `demo-swipe.gif` - Swipe action demonstration
- `demo-widget.gif` - Widget usage demonstration

## Screenshot Guidelines

1. Use clean, representative data
2. Remove personal information
3. Capture in both light and dark mode
4. Use device frames for polish

## Image Formats

- PNG for screenshots and icons
- GIF for animations
- WebP for optimized web display
