Support

Answers to the usual questions. If yours isn't here, open an issue on GitHub and I'll help.

Get in touch: Open an issue · Discussions

Please don't include a secret key, a QR code or a PIN in a bug report.

Adding an account

Tap + and choose how to add it:

  • Scan QR Code — point the camera at the code your service shows.
  • Choose QR Code Image — pick a screenshot of the code.
  • Paste — paste an otpauth:// link.
  • Or type the secret key in by hand. Spaces and dashes don't matter.

Most services use the defaults (time-based, 6 digits, 30 seconds, SHA-1). If yours differs, the form lets you change the algorithm, digit count and period.

The PIN prefix

Some workplace logins want a fixed PIN typed immediately before the generated code. Put that PIN in the Fixed Prefix field and TOTP will prepend it whenever it copies the code or fills it with AutoFill. The PIN is never shown on screen — accounts that have one show a small PIN badge instead — and it is stored encrypted, exactly like the secret.

Setting up AutoFill

iPhone / iPadSettings ▸ General ▸ AutoFill & Passwords ▸ turn on TOTP.
MacSystem Settings ▸ General ▸ AutoFill & Passwords ▸ turn on TOTP.

Add the website to the account's AutoFill Domains field (for example sso.example.com) so it's suggested on the right page. Accounts with a PIN can also fill password fields with PIN + code together.

iCloud sync

Sync is automatic when you're signed in to iCloud, and uses your own private iCloud database. Open Settings ▸ iCloud in the app to see sync status, how many accounts are on the device and in iCloud, and to run a sync straight away.

Codes aren't appearing on another device

  • Check both devices are signed in to the same Apple Account with iCloud Drive on.
  • Turn on iCloud Keychain. Devices share their encryption key through it; if it's off, another device can't read what this one uploaded. The Settings screen tells you which key is in use.
  • A TestFlight build and a build you compiled yourself use separate iCloud environments, so they won't see each other's accounts.

Widgets and Control Centre

Add a widget from the Home Screen or Lock Screen, then choose which account it shows. Tapping it copies the code, including the PIN. The Control Centre control does the same in one tap and can be assigned to the Action button.

The app lock

Turn on Require Face ID (or Touch ID) in Settings to hide codes until you authenticate. With it on, AutoFill, Shortcuts and the Control Centre control also ask before handing over a code, and account names are removed from Spotlight.

Counter-based (HOTP) accounts

HOTP codes advance each time you use them, so they're only available in the app itself — not in widgets, Shortcuts or the Control, where a counter could drift out of step with the server.

Moving to a new device

Sign in to the same Apple Account with iCloud Keychain on, and your accounts arrive by themselves. There is no export file to move, and no account to recover — which also means that if you lose every device and have iCloud off, the secrets are gone. Keep the recovery codes your services give you.
